# Виджеты фестивалей для Scriptable

## Установка

1. Откройте нужный файл в папке `scriptable` и скопируйте его содержимое в новый скрипт Scriptable.
2. Добавьте на экран виджет Scriptable и выберите созданный скрипт.
3. Для `festivals_city_30_days.js` укажите город в параметре виджета. Если параметр пустой, используется Москва.
4. `festivals_all_14_days.js` показывает анонсы всех городов на следующие 14 дней.

Виджет города показывает фестивали на 30 дней. Оба виджета выводят только дату и название.

## API

Скрипты читают публичный маршрут:

`GET /api/scriptable/festivals?days=30&city=Москва`

Параметр `city` необязательный: без него возвращаются фестивали всех городов. `days` ограничивается диапазоном от 1 до 90.

Лента включает только одобренные анонсы с датой начала, у которых событие ещё не завершилось. Ответ содержит название города и события с датой, датой окончания (если указана) и названием. Личные отметки пользователей не выдаются.

Маршрут и виджеты появятся на рабочем сайте после слияния изменений и деплоя новой версии приложения.
