# Cosplay Planner Android App

Этот модуль добавляет базовый каркас Android-приложения с offline-first подходом:

- локальное хранение: `Room`
- API: `Retrofit`
- фоновая синхронизация: `WorkManager`
- DI: `Hilt`
- UI: `Jetpack Compose`

## Что реализовано

1. Полноценная offline-first структура Android (`android-app/`) с тёмной темой по умолчанию и светлой темой.
2. Мобильные API:
   - `POST /api/mobile/login`
   - `GET /api/mobile/bootstrap`
   - `POST /api/mobile/sync`
   - `POST /api/mobile/in-progress/sync`
   - `GET/POST /api/mobile/pigeons`
3. Локальное хранение:
   - профиль пользователя
   - коспланы и карточки «В процессе»
   - фестивали на ближайшие 30 дней и все фестивали с отметкой «Я иду»
   - кэш сообщений «Голубей»
   - очередь синхронизации
4. Правки коспланов и карточек «В процессе» сразу сохраняются в Room. При появлении сети WorkManager отправляет очередь на сервер, затем получает актуальный снимок.
5. Сессия хранится между перезапусками приложения; миграция БД 2→3 не удаляет офлайн-данные.
6. Планшеты:
   - на телефонах фиксируем портрет
   - на `sw600dp+` разрешаем landscape

Вкладка Event Management намеренно не включена в мобильную навигацию.
