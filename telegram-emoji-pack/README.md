# Cosplay Planner — Telegram Premium custom emoji

Статический набор в фирменной ледяной, лавандовой и стеклянной эстетике Cosplay Planner. Контраст рассчитан одновременно на светлую и тёмную темы Telegram.

## Состав

- латиница: A–Z и a–z;
- кириллица: А–Я/а–я, включая Ё/ё;
- цифры: 0–9;
- Коспи: мечтатель и маг;
- кристальные звёзды, блики-кометы и четыре варианта тумана.

Всего 142 emoji. Для каждого подготовлены PNG и lossless WebP размером 100×100 px с прозрачностью. Имена файлов используют Unicode-код символа, поэтому одинаково надёжно работают на macOS, Windows и Linux. Соответствие файлов символам и рекомендуемые базовые emoji находятся в `manifest.csv`.

## Загрузка в Telegram

1. Откройте официального бота `@Stickers`.
2. Создайте новый набор командой `/newemojipack` и выберите статический формат.
3. Загружайте файлы из папки `webp` (либо `png`).
4. Для каждого файла используйте базовый emoji из колонки `telegram_alt_emoji` файла `manifest.csv`.

Исходные фирменные персонажи и звёзды не перерисовывались: они аккуратно адаптированы из ассетов проекта. Алфавиты построены шрифтом Montserrat Medium, с жемчужным бликом, лавандовым стеклом и контуром, читаемым на обеих темах.

Пересборка: `python3 scripts/build_telegram_emoji_pack.py`.
