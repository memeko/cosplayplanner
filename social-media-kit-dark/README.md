# Cosplay Planner — dark horizontal PNG kit

Второй декоративный набор: минимальные вытянутые фоны с большим количеством свободного пространства.

## Направления

- `black-red-01.png` — почти чёрный фон, красная кометная дуга и небольшая звезда.
- `black-red-02.png` — графитовый фон, низкая красная волна и обрезанная краем звезда.
- `chinese-red-01.png` — киноварно-красный лаковый фон и чёрная кристальная звезда.
- `black-jade-01.png` — тёмный фон с тонкой нефритовой лентой.
- `jade-red-01.png` — нефритовый фон и маленький киноварный акцент.
- `black-red-jade-01.png` — почти чёрный фон с пересечением красной и зелёной лент.

Все изображения имеют исходный формат 2172×724 (примерно 3:1), не содержат текста и логотипов. Основная зона оставлена свободной для заголовков, фотографий и элементов оформления социальных сетей.

## Палитра

- near black: `#07090A`–`#111318`
- Chinese red / cinnabar: `#C8102E`
- dark vermilion: `#8F1425`
- jade green: `#007A5E`
- deep emerald: `#043D32`
