# Cosplay Planner — social media decorative PNG kit

Набор собран по текущей визуальной системе проекта и существующим ассетам `foxy.png`, `star.png`, `star2.png`, `icon-512.png`, `logo.svg` и `logo-fox-ears.svg`.

## Визуальный профиль

- Основа: ледяной светло-голубой фон, молочно-белое свечение и полупрозрачное стекло.
- Главные мотивы: пятиконечные кристальные звёзды, четырёхлучевые блики, облака, кристаллы и текучий «лисий хвост»-комета.
- Фирменный акцент: сдержанный фиолетовый `#6C63FF` / `#7B72FF` поверх спокойной голубой базы.
- Характер: магический, дружелюбный, структурный и премиальный; без тёмной игровой агрессии и неоновой перегрузки.
- Композиция фонов: декор по краям, свободный центр под заголовок, анонс или фото.

## Файлы

- `background-square-1080.png` — квадратный фон 1080×1080 для постов.
- `background-story-1080x1920.png` — вертикальный фон 1080×1920 для Stories/Reels.
- `background-wide-1920x720.png` — широкий фон 1920×720 для обложек и баннеров.
- `overlay-crystal-crescent.png` — прозрачная угловая/круговая декоративная рамка.
- `sticker-foxy-wizard.png` — прозрачный стикер с белой лисичкой-магом.
- `divider-comet-ribbon.png` — прозрачный горизонтальный разделитель-комета.

Все изображения созданы без текста и логотипа, чтобы их можно было комбинировать с разными форматами публикаций.
